A feature counts as adopted when its behavior is present; ancestry, a similarly named file, and a release-note title do not establish adoption. Implement only gaps confirmed by the inventory.

## Decisions to keep explicit during implementation

- Permission safety differs by generation. The existing OC1 safety-net failure path accepts according to its old auto-accept policy. The upstream 2.0.4 safety mode holds a request when classification fails. Store and enforce the selected mode with its generation; do not replace the OC1 boolean with an unqualified three-mode value.
- Jev is opt-in in the upstream 2.0.4 product. The current OC2 path can select a free Zen endpoint without a key. W3 must change the default and its visible controls together, so unchosen classification never sends conversation text to a Jev endpoint.
- The upstream file-editor contribution can take priority over built-in previews, including binary image and PDF editors. W4 must define the precedence in one place and keep snapshot, dirty-state, autosave, and explicit save behavior in the existing Files owner.
- Enterprise mode is a security contract, not a Settings preference. W5 must prove that restricted network and extension routes cannot be reached around the UI, and must resolve OC1 provider enforcement before exposing enterprise mode there.
- Spaces work after v2.0.4 is unpublished. Pin and classify it as target-main content, not as part of the v2.0.4 release notes.
