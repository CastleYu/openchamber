DIJIANG 4.0 基于 OpenChamber 1.24.2，参考 2.0.1 接入 OpenCode 1.x/2.x 双内核并自动识别代际。保留旧功能；OC2 历史统计、WebSearch、CodeMode 等按能力启用，不采用 2.x 全量界面布局。

## App

### New

- 已用 OC1 1.18.32 和 OC2 2.0.16 验证真实对话、流式输出和中断，并验证 OC2 fork。本次按 OC1 1.x 代际验收，未单独验证 1.2.27。默认 portable 仍捆绑 OC1 1.18.31，现有外部 OpenCode Server API 可继续连接。
- 新增 CSV/TSV 表格预览、字体预览、文件上传入口和 Cursor/Osaka 主题，这些功能不依赖 OC2。
