# CAgent 消费方边界

基于源代码 `a62bbe7136b740ff08d39b902b98fc4b0ebfe2e6` 于 2026-10-09 冻结。这是 CA-00 迁移决策，不代表适配器已实现，也不是 CAgent 支持报告。请先阅读[架构文档](CAGENT-INTEGRATION-SPEC.md)。[英文原文](../CAGENT-BOUNDARIES.md)包含相同决策。

## 清单与解读

[源代码清单](../evidence/2026-10-08-cagent-consumers.json)记录了 118 项 UI 声明、23 项宿主操作和 496 个命名引用。[处置登记表](../evidence/2026-10-09-cagent-boundaries.json)将每项声明和宿主操作各分配一次，指定契约所有者、所有权类别、迁移决策和验收门槛。每个已记录调用方沿用其所引用方法的处置方式。若保留未使用的声明，它们仍是义务，因为这些方法仍可被调用。

这些分组用于组织审查，不是能力开关。CA-01 必须为每项可调用的后端操作分配独立的操作 ID 和守卫。适配器支持某一方法，并不能启用该组中的其他方法。动态别名、计算式访问和新增消费方也需要相同的分发守卫。尚未解决的调用方所依赖的 CAgent 功能必须保持禁用，直到迁移完成。源代码计数和文档都不能证明服务器支持情况。

| 宿主传输 | 现有 RuntimeAPIs、runtimeFetch 和经过认证的事件传输承载中立操作。不得由浏览器持有 CAgent 凭据，也不得伪造 `/session` 协议。 |

新模块的路径是实现目标，不表示这些文件已经存在。引入模块时，须补充对应所有者的文档。CA-02 会在 CA-01 契约编译通过后，冻结精确的生成适配器路径和可执行命令。

## 功能依赖

除非行内注明可选方案，每行都要求同时满足全部条件。操作名称描述必需语义，不代表猜测 CAgent 端点。每行都适用授权、就绪状态、已接受证据和宿主可用性要求。某个可选功能失败不能禁用无关且已验收的功能。

| 现有功能族 | 所有权 | 所需语义与迁移决策 |
| --- | --- | --- |
| 连接与工作区选择 | 混合 | 已接受的后端身份、明确的工作区绑定和匹配的 epoch。OpenCode 自动检测不得选择 CAgent。 |
| 交互式聊天 | 依赖后端 | 身份、工作区绑定、分发和可观测的完成状态，以及所选模式可能要求的其他决策。会话获取可任选已验证的新建或已验证的绑定现有会话。历史记录和停止操作有各自的门槛。 |
| 会话列表、历史记录与重新打开 | 混合 | 按需支持列表、读取和消息分页；宿主归档元数据必须保留命名空间。消息缺失与读取失败必须区分。 |
| 命令及模型/代理选择 | 依赖后端 | 目录和相匹配的分发/选择操作。提示词不能冒充命令，也不能冒充不受支持的模型更改。 |
| 权限、问题与表单 | 依赖后端 | 针对相应决策类型，支持枚举/观察以及回答/取消语义。自动接受还需要宿主策略和有范围限制的回复授权。 |
| 队列与计划任务 | 混合 | 持久化意图、会话绑定、分发、可靠的活动/完成状态，以及该模式要求时的取消能力；队列命令还需要命令目录。必须先拒绝分发，再取走队列项。切换后保留现有阻塞项。 |
| Assist、目标与会话工作 | 混合 | 中立消息、元数据持久化、活动/完成状态和分发；按实际调用增加子会话观察、选择、命令和取消能力。启用这些读取方前，先移除重建的 SDK 消息。 |
| 路由、控制、上下文与知识 | 混合 | 每个已记录消费方所需的读取/写入/分发操作，以及 OpenChamber 策略/存储。缺少依赖时禁用受影响的操作。 |
| 通知与 PWA 元数据 | 混合 | 宿主投递能力继续可用；由后端提供的标题、选择、消息或实时状态需要相应读取能力。不得把过时历史记录显示为实时活动。 |
| 分享、派生、导入、移动、还原、摘要、收件箱与外壳 | 依赖后端 | 每项操作及其前置读取都需要独立操作。还原暂存和外壳取消需要经过验证的变更/生命周期语义。不得设置笼统的高级功能开关。 |
| 本地文件、Git 与终端 | OpenChamber 所有或混合 | 需要实际宿主访问和授权；后端文件发现是独立操作。AI Git 生成还需要会话/分发/结果支持。远程工作区路径不授予本地访问权限。 |
| 后端配置、提供方、代理、技能、插件与重载 | 混合 | 需要对应的、经过验证的后端读取/写入和应用生命周期。现有设置文件、生成的插件和 dispose 调用仍仅供 OpenCode 使用。 |
| MCP 与凭据/OAuth | 依赖后端 | 该后端必须明确提供目录、连接、资源、凭据和认证操作。保留现有机密信息的所有权，不得回退到 OpenCode OAuth。 |
| CAgent 附加功能 | 依赖后端 | 已注册的版本化扩展处理器、已接受的架构/效果/授权/结果以及受支持的渲染器。新增交互或原生权限需求标记为 `requires-host-development`。 |

机器登记表固定了源方法覆盖范围。CA-01/CA-02 会依据这些语义和每个具体调用方（包括条件操作）生成可执行功能规则。在这些规则可执行并经过验证前，所有 CAgent 功能都保持不可用。本文档不授权根据清单声明启用分组功能。

## 协议泄漏与直接路径

| 证据 | 决策与门槛 |
| --- | --- |
| 源代码清单中的 32 个 SDK 访问引用和 87 个 SDK 导入 | SDK 导入可能只包含类型，并非全部都是调用。保留 OpenCode 适配器；迁移活跃的 CAgent 消费方。CA-01 明确将提供方 OAuth、`useMcpStore`、会话移动、同步和 Git 生成为守卫/迁移目标。 |
| `message-queue/runtime.js` 中回退到 `/session/status`、`/session/:id/message`、`/command`、`/session/:id/command`、`/session/:id/prompt_async` | CAgent 必须使用选定的后端分发器。原始回退路径仍仅供 OpenCode 使用。必须在队列消费或发送之前阻止操作。 |
| `session-goal/runtime.js` 的 `openCodeFetch` 包装器和 `item.raw` 消息重建 | 将 Goal 的协议形状读取器替换为领域操作。不得在 CAgent 上伪造 OpenCode HTTP 响应来保留此包装器。 |
| UI `/api/opencode/runtime`、`/api/sessions/status`、`/api/session-activity` | 将按后端类型区分的身份与代际分开；宿主状态/活动聚合需要中立的后端观察能力。 |

| UI `/opencode/directory` 和后端文件搜索 | 将本地目录创建与后端工作区创建/绑定、后端搜索拆分。`/api/fs/directory-stat` 和 `/fs/*` 按当前访问检查继续由宿主负责。 |
| 队列、计划任务、assist、目标、路由、通知、控制、上下文、知识、session-work 和 session-metadata store 中的 `kernelOperations` 消费方 | 向每个消费方注入受守卫的分发器。缺少可选操作时应阻止相应操作，不得回退到 HTTP、返回空成功或切换到其他后端。后代活动和 PWA 读取也遵循同一规则。 |

## 受保护边界与验收

环境内代理只能写入其任务包允许生成的适配器工作区和经过脱敏的操作夹具。共享契约、操作常量、功能规则、宿主/UI 分发代码、核心测试、参考夹具和工具包运行器由维护者负责，代理只能读取。CA-02 记录文件摘要，并独立于适配器命令拒绝已变更的受保护文件或范围外编辑。

CA-01 必须以带类型的操作和守卫覆盖本登记表，保留 OC1/OC2 行为，并在产生任何副作用前测试不受支持的直接调用和后端切换。CA-02 提供可运行的逐操作任务包，并测试稀疏支持及一个合成扩展。只有 CA-03 能通过本地 API 证据、实时结果和维护者启用，确立真实的 CAgent 支持。未经测试的宿主和未经检查的操作仍不可用，并须说明具体原因。
