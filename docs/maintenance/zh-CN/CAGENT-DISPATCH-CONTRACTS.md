# Agent 调度契约

## 共享 HTTP 契约

`schemas.js` 统一管理分发、尝试查询、持久化尝试、尝试状态及固定错误 schema。路由和持久化复用这些 schema；`schemas.d.ts` 为 `packages/ui/src/lib/agent/client.ts` 提供精确的操作类型。浏览器导入只包含 Zod 和 Agent 常量。客户端解析完整快照及规范化结果、退役端点作用域，并保留不确定写入而不重试。没有实际 UI 消费方或宿主功能批准因此启用。详细中文说明见[共享客户端](CAGENT-UI-CLIENT.md)。

## 受保护的进程启动选择

`startWebUiServer` 现在接受维护者专用的 `agentBackend` 启动选项。`selectAgentStartup` 在生命周期或持久化消费者启动前，严格校验家族及已审查的工件候选。省略时选择 OpenCode；显式 CAgent 加载失败会向上传递，不回退。这个编程组合入口不通过 HTTP、设置或适配器开放。维护者仍须独立验证服务器身份、就绪、授权与验收含义；工件结构校验不能替代这些证据。宿主功能支持仍未启用，选择不代表聊天可用。

`startOpenCodeConsumers` 仅为当前 OpenCode 选择启动自动授权和消息队列。选择退役时停止两者。队列停止后完成的空闲检查不能再启动发送，待发送项在内存及磁盘保留。已经进入的变更不由此取消。这是进程启动入口，完整热切换尚未实现；后续后端使用需重新显式启动并核对独立批准。

英文源文档：[模块文档](../../../packages/web/server/lib/agent/DOCUMENTATION.md)。本模块实现 CA-01 的一部分。服务器已预留经过认证的自有路由，但绑定尚未启用，CAgent 不可用。现有 OpenCode 运行行为保持不变。剩余迁移见[执行检查点](CAGENT-EXECUTION.md)。

`constants.js` 集中定义后端类型、支持状态、操作及拒绝常量。`dispatcher.d.ts` 为宿主清单中的 22 项读取和变更操作定义运行时中立的请求与结果。身份捕获是第 23 项宿主操作，由调度器而非适配器负责。工作区 ID 是后端拥有的标识，不能默认为本地目录。这些契约不要求 SDK 原始载荷。迁移验收前，仍需依据调用方语义补充更完整的消息、决策及 UI 操作契约。

`createAgentDispatcher({ getBinding, attempts })` 在调用时读取宿主权威状态。适配器提供处理器与候选支持声明，独立的宿主验收记录才授予精确适配器修订与能力修订下的访问权限。没有证据及匹配验收记录的支持声明会被拒绝。未验证、不支持、认证失败、未就绪与缺少处理器分别返回不同结果。

`schemas.js` 严格解析全部 22 项操作的输入和输出。调度把解析后的请求副本交给处理器，并返回解析后的结果副本。缺失标识符、无效枚举和多余字段均被拒绝。调度复制后端身份，并在进入处理器前再次检查。身份变化后，读取拒绝过时数据。已进入处理器的变更操作在处理器失败、结果格式无效或身份变化时报告结果未知。身份没有变化时，读取错误交给所属边界处理。本模块不重试、不回退、不跨后端重放。生产变更仍须具备已验收的绑定及已迁移的调用方。

消息现携带会话 ID 和有序分段，不再压平成一个文本字段。文本保留 synthetic／ignored 标记，推理内容单独保存，工具保留调用身份、类型化生命周期、JSON 输入与结果。完成的工具必须提供明确结果，文档规定为空时也须显式返回 null；失败工具必须提供规范化错误。附件携带不透明的宿主资产 ID、MIME 和可选文件名，不接受直接 URL 字段。此契约不解析资产，也不授予文件系统或网络访问权限。附件展示或分发可用前，宿主必须提供经过认证的资产所有者。

消息状态包含 unknown 和 interrupted。创建／完成时间、父消息、Agent／模型选择、摘要、结束原因、错误和用量都是可选观察值，不能伪造默认值。时间采用 Unix 毫秒。token 字段必须为非负整数；费用是已验证的美元金额，无法确认单位时省略。错误／结束原因使用规范化枚举，而非 SDK 错误名称。缺少时间顺序、模型选择或用量时，应禁用依赖这些信息的无人值守行为或计量，不能填入虚构值。本检查点未迁移仍依赖 OpenCode 假设的现有 UI 模型及目标运行器；问答／表单、shell 等特殊消息流程也需先建立各自的消费契约，再声明支持。

权限选项现包含不透明的选项 ID、展示标签、允许／拒绝结果和 once／session／persistent 授权范围。列表必须非空且 ID 唯一。适配器只能映射文档明确支持的范围，不能把不支持的范围升级为持久授权。回复仍携带所选选项 ID。当前 schema 不能证明回复属于仍有效的待处理权限，实际决策消费方迁移时必须与当前请求核对。消息读取结果必须属于请求的会话，单条读取还须匹配消息 ID。合成插入返回其他会话时，操作已产生效果，结果按未知处理。导入在进入处理器前拒绝混合工作区／会话归属。

`createAgentDispatcher` 现可接收宿主拥有的 `attempts` 存储。全部 11 项变更输入都要求请求 ID。没有存储时，变更在进入处理器前被拒绝。`attempts.js` 独占创建意图文件，并在分发前同步落盘 unknown 记录。文件键使用后端家族、连接 ID 和请求 ID；epoch 或适配器修订变化不能让已有意图再次发送。并发预留只有一个成功者。存储失败阻止分发，并保留任何未完成的预留。

预留后，调度器再次检查权限。进入处理器前撤销权限会记录 `not-sent`。进入后的处理器失败、无效或请求 ID 不匹配的回执、unknown 回执及最终持久化失败，都返回 `unknown-outcome`。确认的结果记录 `accepted` 或 `complete`；接受不代表完成。持久化后再次检查最终权限。记录仅包含身份、操作、请求 ID 和尝试状态，不包含提示词、凭据或结果。重启后的读取返回历史记录，不能作为实时活动。损坏或不可用的存储返回错误，不能当成记录不存在。不自动重发、删除，也未增加保留期限策略。原生文件同步已用于进程重启测试；这些测试不能证明断电持久性或 Windows ACL 隔离。生产组合在现有数据目录下提供惰性存储；没有通过验收的分发时，不创建记录。

`readAttempt(expectedIdentity, requestID)` 是宿主拥有的历史访问，不属于适配器操作清单。读取前后都要求绑定已授权、已就绪，并与当前身份精确匹配。身份变化或权限撤销后拒绝返回结果。它不要求当前写入能力，因此操作被禁用后仍可检查已记录的尝试。记录保留原始 epoch 及修订。不存在的记录明确返回 null；存储错误向外传递。查询不访问 CAgent，也不能证明已接受的请求已经完成。

宿主组合必须提供规范化且不可变的绑定。启用记录与处理器注册必须位于环境内 Agent 可写文件之外。manifest 不能直接构造此权限。每个处理器还必须解析真实服务器的响应，再投影为领域数据。这些 schema 验证的是中立契约，不能证明未公开的 CAgent 线路语义。

`createAgentAuthority({ registrations, getSelection, getAcceptance })` 现负责构造这些不可变绑定。受保护的宿主组合提供注册表和两个同步读取端口。注册记录绑定后端家族、适配器 ID／修订版、能力修订版、产物摘要、候选能力和可调用处理器。重复组合或无效注册会使构造失败。选择记录绑定当前连接／epoch、已测试的服务器修订版、就绪和授权状态。无效或未注册的选择不返回绑定；宿主端口不可用时返回固定拒绝。调度器仍分别检查授权与就绪状态。

批准记录由宿主独立提供，不是候选 manifest 中的字段。它必须匹配家族、连接、适配器 ID／修订版、能力修订版、服务器修订版和产物摘要，每项操作都要有非空证据。记录无效、缺失或不匹配时不授予权限。有效批准行只授权具有 supported／adapted 候选证据且已注册处理器的操作；不合格的操作不会移除无关的有效行。每次读取都重新检查宿主端口；未授权或未就绪的选择不读取批准存储。绑定元数据、能力证据和操作列表都是冻结副本，后续源数据修改不能改变在途快照。

权限模块比较宿主提供的摘要，自身不计算文件哈希或验证证据产物。公共路由、用户设置及适配器工作区均不能提供这些端口。生产组合提供只读批准端口及下述初始停用的宿主协调器，因此仍无法启用。该元数据边界不会将可信适配器的可执行处理器置于沙箱内。启用前仍需完成受保护运行器的约束与组合、选择器及消费者迁移。

`createAgentHost` 管理选择的生命周期，组合不可变加载、当前连接传输、独立批准、持久化分发及功能检查。构造不执行 I/O。仅供维护者使用的 `select` 验证配置/连接，在异步加载前停用旧绑定并分配 epoch。失败后宿主保持停用，不静默恢复或重放旧工作。后续选择或 `clear` 使较早加载失效，较早结果不能覆盖新绑定。每个工厂的请求端口随其选择失效，即使修订版被复用也是如此。加载中的工厂没有当前连接。加载后只有独立批准的操作能够分发。凭据留在宿主中，选择只返回冻结的中立身份。

协调器验证结构输入及已验证产物字节，不验证服务器身份或验收证据的含义。就绪、授权、端点及服务器修订版由受保护的维护者组合提供。端点/认证变化要求再次选择，因此会产生新 epoch。候选代码不会收到 `select`、`clear` 或批准写入端口。生产路由现消费协调器的分发器/功能检查，并且受信任的进程启动可选择已审查候选。用户选择器与受保护运行器尚未提供。五种运行端仍维持功能不支持行为。原生 `host.test.js` 串联真实临时产物、持久化批准及本地 HTTP，覆盖撤销、失败/重叠加载和清除后的在途读取。这些合成流程不能证明真实 CAgent 兼容性。

`createAgentApprovals({ directory })` 从宿主拥有的目录读取严格版本 1 记录。`agentApprovalName` 将家族／连接组合哈希为不透明文件名。每次绑定检查最多读取一个 64 KiB 文件，不缓存批准。记录缺失返回 null；JSON／UTF-8 损坏、额外字段、无效证据及范围不匹配均拒绝。目录／文件链接、非文件及读取中观察到的变更也会拒绝。读取器返回独立冻结的批准行，不暴露修改方法。未就绪或未授权的选择在访问文件系统之前返回。

受保护运行器必须掌控目录权限，并在弱 Agent 可写工作区之外写入已审阅的记录。读取器不强制 Windows ACL、不验证证据含义，也不隔离代码。生产组合将其指向现有数据目录下的 `agent-approvals`。构造不会访问或创建文件系统；未启用的选择也无法读取该目录。删除或替换记录会在下一次权限检查生效，包含处理器返回后的检查。

`createAgentApprovalWriter({ directory })` 是独立的维护者端口。所有者须先创建并保护目录；构造不进行 I/O。`write(approval)` 在访问存储前验证完整已审阅契约及序列化后的 64 KiB 上限。它以排他方式在同目录创建仅所有者可读写模式的临时文件，写入并 fsync，关闭后原子替换该范围的记录。替换前失败会保留旧记录并尝试清理临时文件。目录／目标为链接或不符合文件类型时拒绝。`revoke({ family, connectionID })` 只删除该范围；现有目录内缺少记录时返回 false。存储异常只暴露固定代码。

写入器验证记录结构，不验证证据含义或产物来源。只有独立的维护者运行器才能在验证与审阅后调用，不能交给候选代码。没有注册 HTTP 启用／写入路由。所属运行器必须串行处理维护调用并约束目录权限。文件 fsync 与 rename 不能证明 Windows ACL 隔离或目录元数据的断电持久性。真实文件测试覆盖读取器重启、范围隔离、替换、撤销、无效记录保留及权限检查。运行器组合仍待完成。

`artifacts.js` 根据宿主保护的清单，只读验证专用产物快照。有版本的清单列出每个可移植相对路径、字节长度和 SHA-256 摘要。汇总摘要包含排序后的路径／长度／摘要元组。校验拒绝路径别名、不安全路径和超限文件数量或大小。验证拒绝未列出的文件／目录、符号链接和目录联接、缺失文件、摘要／长度差异，以及读取中观察到的变更。哈希使用有界分块读取。固定错误不暴露产物内容或文件系统路径。

`agentArtifactDigest` 可用于生成候选清单，但模型生成的摘要不授予信任。宿主掌控预期清单。`verifyAgentArtifacts` 不导入、启用或写入。`readAgentAdapterArtifact` 在验证读取期间捕获固定的 `adapter.mjs` 入口，返回不可变源码 URL。`loadAgentAdapter` 导入捕获源码，不重新打开原路径。验证不是文件系统沙箱。证据含义、独立批准及真实 CAgent 语义仍需分别检查。真实文件测试与契约编译覆盖这些模块边界。

仅供宿主调用的加载器接收受保护的 CAgent 配置与清单。单个打包入口只导出 `createAdapter(context)`，返回严格的操作能力与处理器。宿主提供适配器身份、修订及已验证摘要，候选导出不能覆盖它们。工厂收到冻结的 JSON 请求端口，使用相对路径、明确方法、可选 query/body，并必须传入当前运行时身份。该端口不接受来源地址、请求头或凭据。传输所有者必须逐次检查当前连接／epoch 并提供认证。HTTP 状态和 JSON 响应体保持明确，由适配器按照文档语义解释。此端口尚未实现二进制与流式契约。

加载会以宿主权限运行经过评审的原生代码，不授予操作批准，也不提供进程沙箱。辅助导入应打包到 `adapter.mjs`；Node 缓存导入模块，因此每次工厂调用必须独立持有状态。源码 URL 不应进入路由或日志。宿主协调器组合加载与传输；受信任的进程启动现提供选择，但受保护批准运行器约束与宿主功能支持仍待完成，加载本身不启用 CAgent 功能。`loader.test.js` 使用合成 API 检查捕获字节导入、严格导出、独立批准、请求验证及工厂上下文隔离。

`createAgentTransport({ getConnection })` 为加载器提供原生 JSON HTTP 端口。受保护宿主端口返回当前 CAgent 身份、以 `/` 结尾的规范 HTTP(S) API 基地址、请求头、授权和就绪状态。端点或凭据变化必须推进 epoch。每次请求解析当前连接，检查完整预期身份，并保留 API 路径前缀。候选输入不能提供请求头或来源地址。GET 请求体、路径归一化及编码后的路径分隔符被拒绝。查询值与 JSON 请求体明确序列化，JSON Accept/Content-Type 请求头由宿主提供。

传输不跟随重定向，也不重试请求。在收到响应头和读完响应体之后，分别检查身份／就绪／授权，拒绝过期结果，并尽可能取消尚未读取的响应体。非重定向 HTTP 错误若包含有效 JSON，仍作为明确状态／响应体交给依据文档编写的 codec 解释。204/205 状态具有 null 响应体；无效 JSON 返回固定拒绝，而非空成功。传输异常只暴露固定代码。此端口本身不授予操作批准，尚未实现流式或二进制传输。宿主协调器提供连接端口，生产状态仍为停用。`transport.test.js` 使用真实本地 HTTP 服务和已验证示例适配器测试完整读取链路，不连接真实 CAgent 服务。

宿主拥有的 `timeoutMs` 默认 30 秒，接受不超过五分钟的正整数，期限覆盖响应头及完整 JSON 响应体。`request` 可选第三参数只接受原生 `AbortSignal`；加载器验证并转发它，不将信号序列化进协议载荷。预取消信号在 HTTP 之前拒绝。每次请求组合独立期限与调用方信号，取消不会影响后续请求。固定传输错误区分超时和调用方取消，不暴露取消原因。自有路由对超时读取返回 504，对取消读取返回 409。变更处理器一旦进入，两种失败均保留持久化未知结果，并拒绝重复分发。取消 HTTP 等待不能证明后端已取消，也不会授予服务器 Stop 能力。UI／HTTP 断开信号传播以及有文档依据的服务器取消，仍属于尚未完成的消费者工作。

协调器还为每个传输实例提供由宿主拥有的 `selectionSignal`。清除、结构有效的新选择，以及显式选择 OpenCode，都会在异步加载前取消旧信号。等待中的响应头和未完成的 JSON 响应体无需等到服务器响应或期限耗尽便会终止。旧接口在 HTTP 之前以 `backend-changed` 拒绝，选择失效优先于调用方取消或超时。后续每次选择拥有独立控制器。已进入处理器的变更在持久化账本中仍为未知，重新选择不能重放相同请求 ID。此机制仅覆盖经提供的传输接口发出的请求；任意原生适配器工作不受沙箱约束，也不会被强制终止。此次生命周期控制没有增加生产选择入口或服务器 Stop API。

`routes.js` 负责 GET `/api/agent-backend/runtime`、POST `/api/agent-backend/dispatch` 和 POST `/api/agent-backend/attempt`。服务器组合将其挂在现有 API 认证门之后、通用 OpenCode 代理注册之前。分发与查询必须提供精确的预期身份。两个 POST 路由都有自己的 JSON 解析器。查询的请求 ID 只放在严格解析的请求体中，不放入 URL。路由返回固定的宿主拒绝码，不暴露异常文本：重复尝试为 409，损坏/不可用存储为 503，进入处理器后的未知结果为 409。未知路径及方法在此命名空间内终止。已验收的绑定可通过与直接调用方相同的宿主守卫执行持久化变更。没有存储时，已验收的写入返回 `write-unavailable`。当前生产调度器没有绑定，因此三个路由均返回 `unavailable`。目前没有设置或适配器 manifest 能改变这一状态。

`describeRuntime()` 提供能力展示快照：身份，以及全部 22 项操作各自的可用性／拒绝码。它读取一份不可变绑定，复用分发资格判断，并包含写入所需的持久化存储条件。它不调用处理器，也不返回适配器证据、原因文字、凭据或线路载荷。经过认证的 GET runtime 路由在序列化前验证完整响应。快照仅提供信息；分发始终重新检查当前权限。仍需迁移功能依赖规则及 UI／自主调用方，才能据此计算其功能可用性。

`features.js` 拥有 17 项固定动作依赖规则，覆盖当前 22 项操作。All-of 规则要求全部操作及前置读取。会话获取接受已验证创建或读取已有会话。可选动作失败不影响无关动作。这些规则尚不是完整产品注册表。队列、目标、同步、附件、权限以外的决策及 CAgent 扩展仍需各自的消费契约和规则。

`createAgentFeatures({ getRuntime, getHostSupport })` 将当前操作可用性与绑定精确身份的宿主实现支持取交集。可选支持端口默认返回 null。实现行缺失、损坏或重复时，全部动作以 `unmigrated-consumer` 关闭；端口抛出错误时拒绝提供可用性，身份过期返回 `backend-changed`。候选适配器不能提供端口或替换冻结规则。生产组合未提供实现端口，因此不宣称真实调用方已经迁移。

`requireFeature(feature, expectedIdentity)` 每次调用都重新检查两个端口。消费者须在取走队列意图或进入流程之前检查，再通过操作守卫分发。该检查不是授权租约，也不执行副作用。直接操作守卫仍保留；真实 UI、快捷键及浏览器关闭后的调用方尚未迁移至功能检查。仅凭 prompt／status 操作可用，不能证明完整交互聊天或无人值守完成语义。

第四条自有路由 GET `/api/agent-backend/features` 在认证后返回经过严格验证的完整功能快照。它不调用处理器，只发送固定拒绝码。没有组合功能服务时返回 503；生产组合中未启用的调度器同样返回 503 `unavailable`。VS Code 通过已有命名空间守卫拒绝该路由。功能快照仅提供信息，不授予后续分发权限。`features.test.js` 和功能 HTTP 测试检查依赖、替代会话获取、宿主迁移、身份、撤销及处理器隔离。

## 后端家族选择

Web 生命周期与 readiness 循环现在消费同一个家族／修订版快照。选择 CAgent 后跳过 OpenCode 启动和监控；直接调用 OpenCode 生命周期操作会在执行前拒绝，异步边界会拒绝已失效的启动或就绪结果。失效启动中新创建的进程会关闭，已有自有进程的关闭能力仍保留。选择修订版变化会重置健康计数和缓存。启动包装器不会在其选择失效后启动 OpenCode watcher。已发出的探测轮次仍可在现有期限内完成，因此这不代表立即取消网络请求。受保护运行器约束、完整能力覆盖及尚未迁移的自有路由／UI 仍是启用前提。本次没有授予任何 CAgent 宿主支持。

协调器默认选择 OpenCode，通过 `getSelection()` 暴露包含家族及修订版的不可变快照。结构有效的 CAgent 选择在加载前推进修订版；加载失败及 `clear()` 均保留 CAgent 家族，且没有活动绑定。只有维护者拥有的 `selectOpenCode()` 端口才能返回 OpenCode，同时停用待完成的适配器加载及选择范围内的请求端口。快照不包含凭据、不执行 I/O，后续选择不会修改旧快照。

Web 入口为 Agent 路由和 OpenCode 内核运行时组合同一个协调器。其选择端口按家族／修订版使 OpenCode 描述符失效，包括返回相同端点的情况。CAgent 产生不支持的描述符，不执行 OpenCode 版本探测。并发刷新和健康探测共享有效结果；仅提交描述符不会停用连接。测试将真实宿主、内核运行时和原生适配器产物组合运行。生产仍无用户选择入口或宿主支持批准，五种运行端上的 CAgent 仍不可用。此守卫覆盖描述符消费者，不能代表所有尚未迁移的自有路由、生命周期操作或 UI 调用方；启用前仍须逐项迁移。

## 受保护的适配任务包运行器

`packet-runner.js` 中的 `createAgentPacketRunner` 接收受保护的宿主定义、冻结的工具包清单，以及独立的检查点读写端口。每个任务包包含一个规范操作、专属候选目录、准确的文本文件白名单、依赖操作和固定命名检查函数。定义和检查点由宿主提供；运行器不从候选清单读取测试命令、可执行报告或批准请求。离线工具包必须提供这套组合，才能宣称交付 CA-02。

检查前，运行器验证受保护目录，捕获大小受限的 UTF-8 候选文件，并按捕获内容验证完整候选目录。额外条目、不安全路径、链接、候选硬链接、工作区重叠、无效 UTF-8 及超限文件／字节均被拒绝。候选摘要只标识捕获内容，不授予信任。检查接收冻结的源码字符串，并返回严格布尔值。运行器自身不导入或执行候选代码。可信样例检查若需原生执行候选代码，必须自行提供有文档说明的执行边界。

检查后，运行器再次验证受保护文件、当前候选内容和所有直接／传递依赖。只持久化工具包／操作／内容身份、命名布尔检查结果、检查点状态及失败次数。报告仅包含固定原因和摘要，不含源码文本、原始异常或路径。`fixtures-passed` 只证明该任务包的固定检查通过，不证明真实服务支持、宿主实现或生产启用。

样例检查返回 false 时消耗一次实现尝试，允许初次尝试及两次修正；第三次失败要求维护者介入，并停止继续检查。设置、边界和检查点端口失败返回受阻结果，不消耗实现尝试。新运行器读取受保护进度后重新验证依赖内容；已验收祖先的内容变更会阻止后续任务。即使已有通过记录，每次运行仍检查自身候选。独立任务包可以继续运行。

单个运行器串行处理调用。下述原生工作区组合补上跨实例互斥和持久化。这两个模块不配置文件系统 ACL，不创建离线包，也不写启用批准。CA-02 必须证明这些边界和可执行命令。原生文件与样例测试只证明已实现的检查，不证明操作系统权限隔离或真实 CAgent 兼容。

### 原生任务包工作区

`packet-workspace.js` 中的 `createAgentPacketWorkspace` 将运行器与已有的维护者专属进度目录组合。该目录必须位于受保护工具包及候选目录之外。模块验证规范原生路径、单链接普通检查点文件、限定大小的 UTF-8 记录，以及工具包／操作身份。检查点缺失时开始该操作；损坏或无法读取时阻止执行。记录按冻结的工具包摘要隔离，不转换旧工具包记录。

检查点写入使用独占创建且仅所属用户可读写的临时文件、文件同步和同目录重命名。替换失败时保留旧记录，仅清理本次写入的临时文件。这保证原子可见性，不承诺掉电后的持久性。维护者必须通过操作系统权限阻止候选写入者修改进度和受保护定义；运行时路径检查不能建立该权限边界。

整个执行过程持有按进度目录原生设备／inode 身份确定的 IPC 监听句柄，排除其他工作区进程。Windows 使用命名管道，Linux 使用抽象 Unix socket。这些进程所属句柄在正常或异常退出后释放，依据 [Node IPC 语义](https://nodejs.org/api/net.html#ipc-support)。其他操作系统在执行边界独立验证之前返回存储拒绝。此限制属于维护者适配运行器，不代表应用运行时支持范围。监听器不接收命令，并立即关闭传入连接。浏览器路由不暴露该入口。

原生 Windows 测试验证了竞争互斥、强制结束持有者、新进程恢复，以及持久化的三次失败上限。尚未验证 Linux 执行、桌面控制台可见性、ACL 隔离或 CAgent 兼容性。样例检查通过仍与维护者启用批准和真实环境验收分开。

## 目标读取器迁移

OpenCode 适配器在消息视图中提供按顺序排列的 `textParts`、`agent` 和 `variant`。目标读取器使用这些字段及现有显式模型、时间、核算字段，不再检查 `raw`。`textParts` 保留文本边界，审计文本不包含推理或工具内容。OC2 用户/合成消息文本成为单个元素；缺少文本时返回空数组。Legacy 在没有 `agent` 时使用 `mode` 提供 Agent。Legacy 的 variant 与当前版本模型的 variant 均在适配器边界投影。

此修改适用于 Web 和共享进程内后端的 Electron。托管移动端和 Capacitor 保持相同的服务器目标循环。VS Code 没有新增目标运行时或 CAgent 支持。目标发送、元数据、状态、活动和事件订阅仍依赖 OpenCode 契约；启用 CAgent 目标前，必须迁移并加以能力约束。中立 CAgent 调度器尚未连接此读取器。其他 OpenCode 调用方仍保留 SDK 形状的视图类型和原始记录。这项准备工作没有启用任何验收或宿主支持条目。

内核 HTTP 回归验证两个协议的投影；不含原始载荷的目标测试验证多段审计文本、模型/Agent/variant 续跑及旧身份拒绝。这些属于 fixture 测试，不能代替真实 CAgent 验收。

聚焦验证使用包内 Vitest 运行器执行 `server/lib/agent/{approvals,artifacts,authority,attempts,dispatcher,schemas,content,routes}.test.js` 与 `contracts.test.ts`。批准测试使用原生文件及链接，跨读取器重启替换／删除记录，并在分发中撤销批准。内容测试检查类型化分段、缺省元数据、权限语义及嵌套导入拒绝。权威测试将合成注册与独立批准组合，涵盖不匹配、撤销及分发。HTTP 测试使用真实 Express 请求、测试认证门及合成的已验收绑定，覆盖请求体解析、拒绝码、身份／可用性快照、无效请求/结果、持久化变更/查询和代理隔离。测试未启动完整生产服务器，也不能证明真实 CAgent 兼容。VS Code 的 `src/bridge-proxy-runtime.test.js` 检查本地或上游转发之前的拒绝。还须使用已安装的 TypeScript 编译器直接编译 `contracts.test.ts`。其中仅用于编译的调用检查逐操作结果类型、完整的操作键覆盖、类型化权威端口，以及缺少工作区/请求身份和未知操作时的拒绝。Web 工作区常规类型检查仅包含 UI/src，而不包含服务器声明文件。
