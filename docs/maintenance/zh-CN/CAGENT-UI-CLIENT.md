# 共享 Agent 客户端

## 受保护的后端家族启动入口

`selection()` 在适配器绑定前读取 GET `/api/agent-backend/selection`，返回受保护的后端家族、宿主选择修订号及客户端端点作用域。权威信息缺失、损坏或读取失败返回固定错误；调用方不能因此推断 OpenCode。A/B/A 退役、调用方取消及释放复用既有请求生命周期。

该描述不含适配器身份、凭据或功能许可。明确选择 CAgent 后，适配器加载失败仍保留 CAgent。

`AgentBootstrap` 和 `BackendGate` 在 Web、Electron 主窗口／迷你聊天及托管移动入口挂载懒加载的 OpenCode 应用前选择家族。Capacitor 先通过 `MobileBackendGate` 复用原生保存实例的连接／认证流程。探测失败允许重试，不能因此选择 OpenCode。端点退役时移除所选应用；过期响应和已释放的 StrictMode 所属实例不能恢复应用。通用外观设置与运行时重置保留在门控之外；门控不会移除所有 OpenCode 模块导入。CAgent 挂载自己的会话页面，操作由能力门槛控制。全部 13 种语言均包含文案。

会话根入口在打开会话前取得匹配的运行时及功能快照。选择描述只提供信息，不是跨后续宿主变化的租约。同端点家族变化需要重新探测；本轮未交付热切换选择器或 CAgent 原生恢复流程。VS Code 保持明确的不支持响应及既有 OpenCode 根入口。

英文交接文档为[客户端模块文档](../../../packages/ui/src/lib/agent/DOCUMENTATION.md)。本中文副本随修改同步维护，最终交接时归档。

`client.ts` 解析 OpenChamber 自有 Agent 路由，返回按操作区分的契约。它不调用 CAgent Server API，也不替代 OpenCode 门面。宿主负责适配器加载、凭据、独立批准和分发。统一 schema 与操作类型位于 `packages/web/server/lib/agent`，浏览器导入不包含宿主 I/O。

消费方为自己的生命周期创建一个 `AgentClient`，结束时释放。生产入口通过 `runtimeFetch` 解析当前端点／认证，并订阅端点退役。`inspect()` 要求完整的运行时／功能快照和匹配身份。后续请求携带它返回的作用域。作用域包含本地端点修订，即使从 A 切到 B 再回 A，旧请求仍失效。宿主分发独立复核后端身份。

传输前解析输入，消费前解析输出。权威读取失败抛出固定 `AgentClientError`，不能变成空成功。分发只发送一次。已进入的写操作若响应丢失、无效或退役，返回 `unknown-outcome`；消费方须保留原请求 ID，使用 `readAttempt()`，不能自动重发。明确的 null 表示没有账本记录。历史记录允许较旧修订，但须匹配请求 ID、家族和连接。

Web、Electron、托管移动端和 Capacitor 使用各自既有 HTTP 运行时入口。VS Code 在宿主实现前，继续对自有路由返回 `unsupported-runtime`。应用根入口使用受保护的家族选择，独立 CAgent 会话页消费此客户端。既有 OpenCode 同步消费方保持独立；生产宿主功能支持仍未提供，本模块没有启用 CAgent 功能。

聚焦检查通过 Bun 运行 `client.test.ts` 和相邻运行时请求／切换测试。测试注入传输入口，不模拟模块，覆盖请求保真、完整快照、A/B/A 退役、释放及不确定写入。[执行检查点](CAGENT-EXECUTION.md)中的原生启动探针还通过该客户端访问真实 loopback 服务。两者使用合成适配器，不构成真实 CAgent 兼容性验收。

## 中立会话状态

配置的 bearer、凭据提供器或额外请求头变化时，生产 Agent 客户端同步退役，中止待完成请求并清空会话。即使端点不变，旧作用域也拒绝分发。已经进入的写操作保留持久记录，供后续查询结果；退役不会重发变更。创建绑定时，命名空间摘要计算或检查期间发生的任何退役也会被拒绝，包括 A/B/A 变化。

| 运行时 | 认证退役行为 |
| --- | --- |
| Web | 共享 Agent 客户端清空 CAgent 会话。 |
| Electron | 主窗口及迷你聊天使用共享客户端。 |
| 托管移动端 | 使用共享客户端行为。 |
| Capacitor | 配置的原生 HTTP 凭据使用共享客户端。 |
| VS Code | 自有 Agent 路由保持不支持；本轮不增加 CAgent 宿主。 |

异步提供器首次解析的凭据建立比较基准。后续变化，包括凭据移除及恢复，在解析请求头时被观察到后会使客户端退役。已替换提供器的结果，以及较早读取返回的不同凭据，均被拒绝。这是在请求边界观察变化，不是后台检测或权威用户身份识别。

通知不含凭据，也不授予功能支持。仅 URL 认证令牌刷新不会使客户端退役。仅 cookie 用户切换仍需要宿主身份支持。记录摘要读取配置的同步凭据，并不代表自定义提供器的解析结果。凭据轮换仍会改变该命名空间；本轮既不提供自定义提供器的用户隔离，也不提供跨轮换恢复。

`conversation.ts` 中的 `AgentConversation` 直接消费客户端，不使用 OpenCode 线协议模型。调用方提供已检查的后端快照及明确的不透明工作区／会话 ID。打开会话时验证返回的归属；历史读取拒绝其他会话记录和重复身份。项目路径、时间戳、提供商／模型和用量缺失时保持缺失，不推断本地目录映射。

控制器保留规范化分页顺序，按原位置更新重叠 ID；部分刷新无法证明删除时保留此前加载的记录。不按缺失时间排序，不从历史推断活动，不自动轮询，也不伪造乐观服务器消息。读取失败保留旧数据，并呈现独立失败状态。新读取、发送、会话选择及端点退役会使过期结果失效。端点退役同步清除可见会话状态，包括 A/B/A 切换。

读写前检查操作及功能快照，宿主分发独立复核当前权限。发送只捕获一次工作区／会话及请求 ID。已进入的写入若结果未知，保留该状态并阻止再次发送。`resolve()` 查询持久化宿主尝试账本，不重发；null 证据不解除不确定性，新请求也不会被旧查询覆盖。发送的 accepted／complete 回执不证明助手或工具执行完成。释放时移除监听器和内存状态。

`AgentRequestJournal` 是通过注入使用的持久化身份存储。生产所属模块在构造控制器前提供存储入口和不透明命名空间。`createAgentChatBinding()` 在内存中对端点键、bearer 和额外请求头计算摘要，并提供浏览器存储。取得快照后再次核对作用域；加密功能或存储不可用时明确失败，不退回仅内存模式。原始 URL 和凭据不会成为存储键。该摘要不包含仅使用 cookie 认证时的用户身份变化，因此尚未证明此情形下的账户级隔离。不注入记录存储时，连续性仅限于控制器生命周期。

注入后，发送会在分发前同步记录家族、连接、工作区、会话和请求 ID；持久化失败会阻止传输。它不保存提示、凭据或线协议载荷。每个请求有独立且带版本的严格 schema 记录，最多 16,384 个 UTF-16 代码单元，ID 最多 1,024 个，命名空间最多 128 个。存储失败和损坏记录返回明确错误。读取仅检查指定归属，损坏记录不能阻断其他会话。记录不会自动淘汰。多个实例保留不同请求的记录；这不是跨窗口发送锁。

重建控制器后，未解决记录恢复为未知并阻止新发送。匹配的权威 accepted／complete／not-sent 证据仅清除对应请求；其他待确认请求仍为未知。清理失败保留不确定状态和记录。宿主报告重复请求时，也保持未知直到查询此前结果。传输前取消会删除已知未发送的标记。请求身份连续性不能推断活动或助手完成。当前命名空间仅在端点和凭据输入不变时保持稳定；凭据轮换会改变命名空间。生产启用前，跨轮换恢复和仅使用 cookie 认证时的用户隔离仍需要身份支持。恢复错误不能删除不确定记录。

Web、Electron、托管移动端及 Capacitor 通过 CAgent 页面挂载此控制器。VS Code 保持自有路由拒绝。在页面、观察策略及全部已记录消费方通过门槛之前，宿主支持仍不可用。合成测试不能证明真实 CAgent 验收。

## CAgent 会话页面

`CAgentApp` 拥有连接绑定，卸载时释放，包括清理后才返回的绑定。它绑定已有的不透明工作区／会话，不创建会话，也不从本地路径推断 ID。操作遵守已检查的操作和功能门槛。明确刷新独立读取历史及状态；一项读取失败仍保留其他成功数据。状态只来自 `getSessionStatus`，状态读取失败时显示未知，不将以前活动显示为当前状态。

发送前页面再次读取状态，仅当结果属于绑定会话且为 idle 时分发。每个新请求使用一个 UUID。结果未知时保留草稿并阻止新发送；结果查询使用原请求身份，不重发。accepted／complete 回执显示为接收确认，不能代表助手完成。支持分页及规范化文本、推理、结构化工具数据和附件标签，不伪造附件下载 URL。决策、取消、创建、目录和 CAgent 扩展仍待完成，因此生产功能支持保持关闭。
