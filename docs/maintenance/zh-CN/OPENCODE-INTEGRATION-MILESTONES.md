## 版本边界

这组能力计划使用 DIJIANG 5.x，衔接当前 4.0 基线。以下子版本是同一个 Agent 集成里程碑内的交付节点，遵循 [BUILD.md](../BUILD.md) 中由维护者划定的功能范围。规划阶段不修改 `featureVersion`、包版本、标签或发布策略。上游包版本独立维护。

早期 Release 仅开放已完成范围，不代表完整 Legacy 1.2.27 或真实 CAgent 兼容。2026-10-09 维护者调整顺序：先完成 CA-01/CA-02 架构及文档，验证原功能，构建并发布临时 Release，再开始其余 INT。CA-03 留作环境内验收，不阻塞此工具包发布。5.0–5.13 编号为计划编号，发布前核对；稳定任务 ID 保留追踪。

## Goal 轮次范围

根据维护者要求于 2026-10-10 更新。每个 goal 轮次交付跨所属模块的可用流程。保留现有任务 ID、依赖与验收门槛；本分组调整执行粒度，不增加功能范围或修改发布版本。

每个实现轮次包含关联实现、专项失败与回归检查、适用的运行时／构建验证、实际差异审查、同步的英文交接与中文归档，以及附带证据检查点的本地提交。承诺批次前及每个里程碑边界读取实时周额度。剩余低于 10% 或预计批次超出可用额度时停止。分别记录通过、失败及无法执行的检查。

每轮同时执行[临时文件清理要求](OPENCODE-INTEGRATION-SPEC.md#开发临时文件清理)，推进前在证据检查点记录清理结果及有理由保留的文件。

## 完成契约

### INT-00：证据与范围

固定实施工作树 SHA，并与此次核查基线比较。并发进行的上游引入应单独记录为建议范围，不能在节点执行中移动目标。核对遗留的失败／未运行测试，判断哪些影响本次范围。历史测试报告不等于干净基线。

将现有接口台账扩展为当前实际使用的操作清单，并对应 Legacy 分组 L01-L15。设计转换前先检查现有模式设置、持久化数据及 OC1/OC2 契约。按照 SPEC 3.1，将现存 SDK/HTTP/SSE 泄漏逐项对应到负责人及明确的迁移或保留决定。

通过条件：每项原始 3.X 需求及新增 Legacy 分组都对应负责人、当前证据、里程碑和验收检查。影响所选工作的当前运行时验证缺口已经解决，或明确阻塞对应工作。精确 Legacy 证据不是本节点的通过要求。

### CA-00：CAgent 操作盘点与边界冻结

在 INT-00 之后，盘点所有已使用操作，包括关闭浏览器后运行的调用者，并将当前功能分类为 OpenChamber 自有、依赖后端或混合功能。冻结 CAgent 的具体模块图、待迁移的协议假设、共享 UI／运行时／宿主归属及受保护文件范围。未知的 CAgent 信息继续标为未知，不假设任何端点、schema、功能或支持状态。

通过条件：每个已使用操作及调用者都对应契约负责人、当前证据、迁移决定和后续验收门槛。生成的清单覆盖直接调用与自主任务调用，并列明受保护的共享文件。实施不得基于猜测的 CAgent API 启动。

已接受的源码分类：[调用边界](CAGENT-BOUNDARIES.md)与[处理注册表](../evidence/2026-10-09-cagent-boundaries.json)。覆盖检查确认恰好分配了 118 项 UI 方法、23 项宿主操作及全部 496 处已记录引用，没有遗漏、多余或重复方法。这是迁移范围验收；可执行守卫和真实后端支持仍属于后续门槛。

### CA-01：类型化宿主契约与守卫

实施从[最小会话路径](CAGENT-INTEGRATION-SPEC.md#先跑通最小路径再扩展覆盖范围)开始，通过真实应用消费者与精简样例后端运行。扩展可选操作覆盖范围前，完成其失败和不可用功能检查。这项内部试点不增加发布版本号，也不放宽下述完整通过条件。

依据实际消费者定义领域契约，只迁移这些消费者需要的协议假设。将一个运行时中立的 CAgent 适配器放在可信的 Web 后端或 VS Code 扩展宿主；Electron 复用进程内后端。在分派时检查权威后端身份和能力，并在产生副作用前明确拒绝不支持的操作。保留 OpenCode 行为并运行 OC1/OC2 回归。

通过条件：类型化宿主操作契约覆盖 CA-00 清单；守卫同时作用于 UI、直接调用者和自主调用者；身份变化会使旧工作失效，且不会跨后端重放。针对性 OC1/OC2 回归通过。没有本地运行时证据时不得宣称支持 CAgent。

[消费契约迁移](CAGENT-CONSUMER-CONTRACT.md)属于本阶段的通过门槛。缺少时间戳、提供者／模型信息或本地目录映射的合成后端，必须通过实际聊天和同步消费者的验证，且不伪造字段。可选引导读取失败不能清除成功获取的对话数据。每项已启用功能都要列出已迁移的调用者；未迁移的调用者使该功能继续不可用。

### CA-02：可运行的离线适配工具包

交付完整可运行的任务包工具链，不能只交规划文档。包含受保护的参考测试和样本、生成的操作桩／常量、确定性生成器、schema、离线依赖和命令、修改文件白名单校验、功能覆盖检查，以及任务包／报告生成。用刻意精简的样例后端和独立的合成扩展功能样例验证工具包；两者都不代表真实 CAgent 行为。

通过条件：干净的离线工作区能运行文档中的命令。精简适配器正确拒绝不支持的操作，并在错误启用依赖功能时使校验失败；合成扩展只能通过已注册的类型化处理器通过检查。修改受保护测试／契约，或在没有关联证据时启用功能，都必须使校验失败。必要检查失败时返回非零状态和精简机器可读结果。

文档收集流程还要通过[工作手册中的判断用例](CAGENT-ADAPTER-WORKBOOK.md#从接口文档到适配器的判断)。受保护的预期结论覆盖结构映射、语义差异、功能缺失、冲突证据及新增能力。仅有端点清单不能满足功能覆盖要求。[功能处理报告](CAGENT-ADAPTER-WORKBOOK.md#功能处置与扩展)须校验每个必填列并拒绝缺行；样例证据不能启用真实 CAgent 功能。

还要通过[弱 Agent 任务包流程](CAGENT-ADAPTER-WORKBOOK.md#弱-agent-的任务包执行)的全新上下文完成、遇冲突停止及中断恢复演练。脚本检查与模型试验分别记录；模型自行报告成功不能推进验收。

CA-02 冻结[本地模型工作预算](CAGENT-ADAPTER-WORKBOOK.md#本地模型工作预算)，演示必需输入超限时如何拆分任务包，并记录演练的执行成本。生产操作分发使用已验收代码，不依赖模型进行路由或转换。

CA-02 还须验证[功能判定示例](CAGENT-ADAPTER-WORKBOOK.md#功能判定示例)和[文档变化处理流程](CAGENT-ADAPTER-WORKBOOK.md#文档变化与重新验收)。CA-03 记录真实契约修订版和维护交接。契约变化后，不能仅因旧修订版曾通过验收而保留受影响能力。

CA-02 还要交付[模型校准样例](CAGENT-ADAPTER-WORKBOOK.md#本地模型校准与任务分配)，演示所有任务分配结果，包括可用的维护者独立完成路径。CA-03 在实现真实 API 映射前，使用实际本地模型运行这些样例，并记录选定工作范围。校准不能替代操作或功能验收。

### CA-03：本地 CAgent 适配与真实验收

CA-01 至 CA-03 还须满足[工作流验收契约](CAGENT-WORKFLOW-ACCEPTANCE.md#里程碑证据)。运行时模型质量、适配模型校准和 API 支持分别记录处理结论。最小交互路径验收后，无人值守工作流仍可保持禁用，不能绕过自身准入检查。

先使用有文档依据的真实 CAgent 操作验证同一最小路径。如果无法保留必需的聊天语义，记录缺口并保持聊天禁用。仅验收只读操作不能完成本阶段。路径跑通后，在验收前完成全部功能和扩展清单的处理结论。

在目标环境中使用实际 API 文档和隔离的 CAgent 服务器运行工具包。实现最小可用对话路径，并为所有现有已使用功能，以及 API 文档中发现的额外功能，给出处理结论。未验证或不支持的功能都要附原因并保持禁用；固定扩展模型无法保留语义时记录 `requires-host-development`。维护者只显式启用已验收的适配器版本。

通过条件：本地真实服务器可完成最小对话，并能观察结果；若支持历史和重开，也需覆盖这些流程。每个声明可用的宿主都通过真实连接流程。证据报告完整记录现有及新发现的功能，包括不支持和未验证项，并包含对禁用功能的直接调用拒绝测试。本地维护者审查证据并显式启用该版本。无法访问环境或文档时，CA-03 真实验收仍未验证；维护者授权的工具包 Release 发布后可开始其余 INT。模拟不能通过此门槛。

使用工作手册任务包，记录目标环境内实际本地 Agent 的适配试验。失败任务包保持禁用，报告其证据缺口；维护者补完时仍使用相同验收检查。

本地模型试验按工作手册预算记录工作量、受保护检查结果、修正次数、维护者介入次数和耗时。无论整体试验成功率如何，失败或尚未检查的操作都保持禁用。

### INT-00L：精确 Legacy 证据

取得精确 1.2.27 源码／schema 和隔离的可执行程序／端点，记录来源与脱敏样本。确定身份探测、实际使用的协议契约和 dispose 范围。调查幂等键支持、保留期及请求 ID 结果查询，不预设任何能力存在。区分缺少证据和已经确认不支持的行为。

通过条件：证据足以实施首个 Legacy 对话，并明确其他操作各自的门槛。任何未解决的契约在取得证据前保持禁用。若无法运行精确 1.2.27，Legacy 真实运行门槛保持阻塞。在 CA-02 临时 Release 发布后，INT-01/INT-02 的当前运行时工作、INT-06 及独立 UI 工作无需等待 Legacy 实测。

### INT-01：身份和适配器边界

负责共享描述符／兼容配置／常量、服务器／扩展组合、UI 分派和直接调用清单。在不改变当前 OC1/OC2 含义的前提下加入 Auto 和手动选择。在启动加载或写入前绑定兼容配置与能力。尚无通过验收实现的 Legacy 操作明确失败。
