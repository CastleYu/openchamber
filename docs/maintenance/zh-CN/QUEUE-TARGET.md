# 排队消息的原配置目标

英文契约：[宿主队列](../../../packages/web/server/lib/message-queue/DOCUMENTATION.md#original-configured-target)。

宿主用已确认的连接配置、内核代际及模式生成私有 SHA-256 归属；托管模式还包含实际解析的程序和工作目录。端口和运行时 epoch 不参与，同配置重启保留归属。此值代表配置意图，无法证明同一 URL 后的外部服务仍是原实例。

新消息由宿主标记，忽略客户端伪造归属；公开投影仅含 ready、target-changed 或 target-unknown。旧磁盘记录及旧浏览器迁移保持未知。归属变更／未知时保留消息，禁止自动及手动发送，仍可编辑或移除。编辑取回完整附件及上下文。取回接口接受 purpose: send（默认）或 edit，异步归属读取后再次检查切换暂停。

同会话 ID 的不同目录追加返回 409，防止旧消息错投。20 条／50 会话容量满时拒绝新项目，保留已有意图。session.deleted 仅删除事件发生前观察到且归属匹配的项目。目标读取失败保留消息并令新增请求返回 503；复用现有重连及派发调度，无新增轮询。共享 UI 显示暂停原因，禁用发送，保留编辑／移除，13 种语言同步。VS Code 前台队列的归属接入仍属于 R1 待办。
