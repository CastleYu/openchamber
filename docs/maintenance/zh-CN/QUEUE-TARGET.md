# 排队消息的原配置目标

英文契约：[宿主队列](../../../packages/web/server/lib/message-queue/DOCUMENTATION.md#original-configured-target)。

宿主用已确认的连接配置、内核代际及模式生成私有 SHA-256 归属；托管模式还包含实际解析的程序和工作目录。端口和运行时 epoch 不参与，同配置重启保留归属。此值代表配置意图，无法证明同一 URL 后的外部服务仍是原实例。

新消息由宿主标记，忽略客户端伪造归属；公开投影仅含 ready、target-changed 或 target-unknown。旧磁盘记录及旧浏览器迁移保持未知。归属变更／未知时保留消息，禁止自动及手动发送，仍可编辑或移除。编辑取回完整附件及上下文。取回接口接受 purpose: send（默认）或 edit，异步归属读取后再次检查切换暂停。

同会话 ID 的不同目录追加返回 409，防止旧消息错投。20 条／50 会话容量满时拒绝新项目，保留已有意图。session.deleted 仅删除事件发生前观察到且归属匹配的项目。目标读取失败保留消息并令新增请求返回 503；复用现有重连及派发调度，无新增轮询。共享 UI 显示暂停原因，禁用发送，保留编辑／移除，13 种语言同步。VS Code 的前台队列归属行为见下文；跨客户端协调及完整 webview 验收仍为 R1 待办。

## VS Code 前台队列

保留现有前台队列，入队时通过扩展宿主的 queue-target 连接路由读取配置归属，随完整消息持久化。并发读取合并，启动／重连同步及手动取回发送时刷新状态，不新增轮询或服务端队列。旧消息缺少归属、读取失败或目标变更时暂停发送，仍能编辑／删除。容量满时拒绝新增，保留已有消息。手动发送失败恢复原消息及归属；自动发送失败保留原项。

排队的普通消息、命令及 shell 请求携带私有目标头；OC2 的模型／Agent 选择和合成上下文写入也携带。扩展在解析当前内核后、实际转发前校验，随后剥离该头。错目标／无效归属返回 409，不可用返回 503，均不向上游发送。普通即时发送沿用原路径。该归属只证明配置意图，不能证明同 URL 后的远端实例。SDK 与宿主边界回归覆盖此契约；跨客户端协调、完整共享 webview 验收和控制台闪现观察仍未完成。
