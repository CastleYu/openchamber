# OpenChamber 2.0.4-DIJIANG.5.0-DEBUG

此 CAgent 宿主临时预览从独立的 `codex/cagent-integration` 分支构建，保留仅通知更新策略，不是并行的 DIJIANG 4.1 构建。

## App

- 新增维护者拥有的 CAgent 启动选择、类型化宿主分发、绑定修订的独立批准与撤销，以及持久化变更结果。
- 不支持和未验证功能保持不可用。CAgent 模式下拒绝通用 OpenCode HTTP 和事件请求，定时任务在认领持久化时段前拒绝。
- 提供离线文档映射与适配包工具链。弱编写 Agent 针对受保护夹具修改范围受限的处理器；有限新增动作使用已审阅的清单和处理器。

真实 CAgent API 映射、目标权限、本地模型校准及环境验收仍未验证。合成测试不授予支持。仅已迁移且拥有独立当前批准的消费者可开放。VS Code 的 CAgent 仍不支持。本预览不交付 Legacy OpenCode 1.2.27 或其余 INT 工作。

维护者在选择 CAgent 前须准备受保护的批准／变更尝试存储及已审阅启动文件，参见[启动契约](../CAGENT-DISPATCH-CONTRACTS.md#受保护的进程启动文件)和[适配工作手册](../CAGENT-ADAPTER-WORKBOOK.md)。构建及打包启动证据须独立审阅后再使用本预览。[英文版](../../releases/2.0.4-DIJIANG.5.0-DEBUG.md)用于交接，本中文审阅副本保持同步，最终交付时归档。
