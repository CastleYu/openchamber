title: 自 1.22.0 以来的更新历史
---

完整汇总自 1.22.0 起的官方和个人版更新，包含 1.22.0 本身。核对日期为 2026-09-24。这是历史回顾，其中的历史条目不代表全部都是下一版新增功能。

官方条目标明引入相关行为的社区版本或 main 分支后续改动，个人版条目涵盖累计个人改动。本次整合包含官方 1.24.2 及 main 分支截至 `0af1eb00c` 的改动，包括 OpenCode 2.x 迁移。已发布的 v2 预览仍是独立构建，main 分支另行完成了 2.x 迁移。早期行为可能已被后续条目调整。本汇总截至 1.24.2-DIJIANG.3.7。

阅读时请区分两点。官方 1.23.1 移除了 MCP 自动重连，当前个人版保留带空闲释放保护的托管重连。官方桌面更新器改进描述的是社区构建，个人版仅提示更新。“便携”指可执行文件，设置和会话数据仍使用既有用户目录。

官方来源：[1.22.0](https://github.com/openchamber/openchamber/releases/tag/v1.22.0)、[1.22.1](https://github.com/openchamber/openchamber/releases/tag/v1.22.1)、[1.22.2](https://github.com/openchamber/openchamber/releases/tag/v1.22.2)、[1.23.0](https://github.com/openchamber/openchamber/releases/tag/v1.23.0)、[1.23.1](https://github.com/openchamber/openchamber/releases/tag/v1.23.1)、[1.24.0 至 1.24.2](https://github.com/openchamber/openchamber/releases)、[上次整合以来的 main](https://github.com/openchamber/openchamber/compare/83ec4fbde...0af1eb00c) 和 [v2 预览](https://github.com/openchamber/openchamber/releases/tag/v2-preview)。预览条目仅记录已发布快照，不描述未发布的分支工作。

个人版来源：[已发布的 3.1 构建](https://github.com/CastleYu/openchamber/releases/tag/v1.23.0-DIJIANG.3.1)、[相对官方 1.23.0 的累计差异](https://github.com/CastleYu/openchamber/compare/d073858d...9ab28d4a) 和[文件打开行为](../../../../docs/maintenance/FILE-OPENING-3.0.md)。审计覆盖 1.22.0 标签之后至个人版 3.1 的 301 个提交，其中官方 229 个、个人版 72 个，另核对官方 1.23.1 的 46 个提交。同时核对了 69 个 PR 的说明，以及五个稳定版发布来源中的全部应用和 VS Code 条目。

“应用”涵盖网页端、桌面端和移动端，但每项功能仅适用于实际提供它的平台。VS Code 按实际挂载的界面单独列出。仅测试改动、合并记录和已回退的中间行为归入最终改动或维护条目，未来维护计划不会写成已实现功能。

## 应用

### 新增

- 官方 1.24.2 后的 main / OpenCode：共享界面迁移至 OpenCode 2.x，采用新版会话与事件接口、托管 OpenCode 2.0.15，并可恢复旧版 CLI 创建的会话。
- 官方 1.24.2 后的 main / 文件：以成品视图预览音频、视频、CSV 表格、字体和图表；可从文件夹菜单或文件树工具栏上传文件，代理也可让应用打开生成的文件。
- 官方 1.24.2 后的 main / 扩展：已安装扩展可提供代理浏览器，并显示可接管、再交还代理的实时画面。
- 官方 1.24.2 后的 main / 聊天：可从代理回答分叉会话、在空的侧边栏分组创建会话，并通过 Console 登录 OpenCode Go。
- 官方 1.24.2 后的 main / 主题：新增内置 Cursor 与 Osaka Jade Refined 配色。
- 官方 1.24.2 后的 main / 隔离空间：可将项目代码带入隔离空间，同时保留其出口管控边界。
- 官方 1.24.2 后的 main / 侧边栏：在分组和时间线会话视图之间切换，并可选显示会话活动旋转图标。
- 官方 1.24.2 后的 main / 权限：代理申请编辑文件权限时，可以预览文件补丁。
- 个人版 / 测试：DIJIANG 回归测试文档列明特性契约和运行器，覆盖 Windows 进程、文件、更新策略及双语历史检查。
- 官方 1.24.2 / 会话：折叠的文件夹和分组会显示代理正在等待权限或回答。
- 官方 1.24.0 / 扩展：支持带面板、页面和聊天操作的第三方工具，并提供扩展 SDK。
- 官方 1.24.0 / 主题：从 Open VSX 浏览或导入 VS Code 主题，选择颜色变体并删除已导入主题。
- 官方 1.24.0 / 项目：为每个项目及其工作树的新聊天选择默认代理（感谢 @MltStephane）。
- 官方 1.24.0 / 文件：关闭编辑器后仍可保持文件树打开（感谢 @cmdaltctr）。
- 官方 1.24.1 / 聊天：可通过文件选择器、粘贴或拖放将文件和图片附加到 `/btw` 消息。
- 官方 1.24.1 / Mini Chat：可从消息操作菜单使用已安装的扩展。
- 个人版 / 聊天与文件：聊天中支持渲染 PlantUML 图并将源码导出为 `.puml`，可预览 `.puml`、`.plantuml` 和 `.pu` 文件。Mermaid 提供九种可选风格，包括原生和手绘渲染。两种图表均支持 SVG 和 PNG 导出。
- 个人版 / 设置：离线保留完整的官方与个人更新汇总，支持按来源和应用筛选。自 DIJIANG.3.3 起，全部条目提供简体中文，切换语言时保留筛选条件。感谢 @CastleYu。
- 官方 1.23.0 / Git：网页端和桌面端的变更视图可通过每个变更块旁的控件，单独暂存、取消暂存或丢弃该块。感谢 @LABCAT。
- 个人版 / 文件：在文件面板预览视频、音频、图片和 SVG，提供播放控件；格式无法解码时可交给外部应用打开。感谢 @CastleYu。
- 官方 1.22.0 / Linear：在“设置 → 集成”连接工作区，浏览和筛选议题，并从议题创建会话或工作树。OpenChamber 会向 Linear 回报会话进度，也可将议题附加到下一条消息。感谢 @AlexKutas。
- 官方 1.22.0 / Git：包含多个仓库的项目可在 Git 标签页切换仓库。差异、拉取请求、变更导览、移动端变更视图和工作状态都会跟随所选仓库。感谢 @jaygupta17。
- 官方 1.22.1 / 消息队列：会话忙碌时排队的消息改由 OpenChamber 服务端发送。关闭发起排队的标签页后仍会发送，所有设备显示同一队列。
- 官方 1.22.1 / Git：有未提交改动时切换分支，会先弹出对话框要求提交或还原，也可选择推送。推送失败会取消分支切换。感谢 @yulia-ivashko。

- 官方 1.22.1 / Git：移动端变更视图新增分支选择器。感谢 @yulia-ivashko。
- 官方 1.22.1 / 设置：界面字体新增 Fixel Text。
- 官方 1.22.1 / 用量：支持跟踪 exe.dev 的用量周期。
- 官方 1.22.1 / 桌面端：开发服务器预览支持通过私有中继访问。
- 官方 1.22.2 / 聊天：新增提示词历史。在输入框按上下箭头可找回先前的提示词及附件，重新加载后仍保留。默认仅涵盖当前会话；可在“设置 → 聊天”扩展到此服务器的所有项目，并设置保留数量，默认为 40 条。感谢 @mattv8。
- 官方 1.22.2 / 聊天：“设置 → 聊天”新增“Enter 发送”开关。开启时 Enter 发送、Shift+Enter 换行，关闭时反过来；Ctrl/Cmd+Enter 始终发送。主动切换前保持原有行为。感谢 @claymor333。
- 官方 1.22.2 / 服务端：可用 `OPENCHAMBER_CHATS_DIR` 更改无项目聊天的存放目录，适用于 OpenCode 以其他用户运行的部署。感谢 @steffenmaechtel。
- 官方 1.22.2 / 命令行：Linux 上执行 `openchamber startup enable` 时，如服务会在注销后停止，将给出提示和保持服务运行所需的 `loginctl` 命令。感谢 @IbrahimKhan12。
- 官方 1.22.2 / 工作树项目操作：工作树内的会话可以使用父项目保存的操作。感谢 @mattv8。
- 官方 1.23.0 / 轮次统计：每轮完成后，工作状态面板显示响应速度、模型与工具耗时、Token 数和报告的费用，默认开启。感谢 @alvins82。

- 官方 1.23.0 / 计划：可将计划移入仓库，或让计划标签页指向项目内已有的 Markdown 文件目录。

- 官方 1.23.0 / 移动端：可在变更面板比较分支和审查单次提交。感谢 @gaojunran。
- 官方 1.23.0 / 移动端：可在手机设置中管理片段、智能体、命令、插件和技能。
- 官方 1.23.0 / 移动端：在会话抽屉点击项目名旁的加号，可在该项目根目录创建会话。
- 官方 1.23.0 / 会话：网页端和桌面端的新会话项目选择器支持按名称或路径搜索项目。感谢 @maximtop。
- 官方 1.23.0 / 会话：网页端和桌面端的侧栏或归档搜索支持粘贴完整会话 ID，以精确查找会话。感谢 @yulia-ivashko。
- 官方 1.23.0 / 聊天：回复中的 Markdown 折叠章节可展开或收起，回复仍在生成时也能操作。

### 改进

- 官方 1.24.2 后的 main / 会话：侧边栏打开和滚动大型列表时占用更少内存，子智能体的实时活动仍归属于父轮次。
- 官方 1.24.2 后的 main / 桌面端：托管 OpenCode 与 CLI 升级可从旧安装恢复，冷启动后更快显示可用窗口。
- 官方 1.24.2 后的 main / 移动端：选中文本的评论改用输入框和引用预览；评论被拒绝后保留草稿。
- 官方 1.24.2 后的 main / 启动：桌面端在主进程继续加载时显示首个窗口，服务器集成按需加载，全局会话列表先显示第一页再加载后续页。
- 官方 1.24.2 后的 main / 内存：按完整会话历史回收空闲缓存，避免固定会话保留所有对话内容块。
- 官方 1.24.2 后的 main / 文件：已认证用户显式读取工作区外文件时无需单独授权令牌，仍遵守系统权限和写入边界。
- 官方 1.24.2 / Diff：点击折叠区即可加载并显示文件周围的行，并显示加载状态。
- 官方 1.24.2 / 界面：在大屏幕上加宽侧栏，同时保持聊天可见。
- 官方 1.24.1 / 会话：大型会话列表打开更快、占用更少内存，并在多个项目间滚动更顺畅（感谢 @deatheros）。
- 官方 1.24.1 / 聊天：代理思考或生成回复时占用更低 CPU（感谢 @deatheros）。
- 官方 1.24.0 / 桌面：应用窗口打开更快。
- 官方 1.24.0 / 会话：侧栏固定标题在分组间平滑淡入淡出。
- 个人版 / 图表：点击图表打开大图，支持滚轮缩放、左键拖动，以及重置、复制和导出的右键菜单。默认 Mermaid 线条在深色模式下更加清晰。原生 Mermaid 和 PlantUML 等待流式输出结束后渲染，关闭动画时也遵循这一规则。目录轮询结果未变化时不再发布新的文件列表状态。
- 官方 1.22.0 / 聊天：从侧栏打开会话时定位到最新消息并保持位置。切换会话不再跳动、只渲染半段对话、交叉淡入淡出或改变标签标题位置。
- 官方 1.22.0 / 语音：本地文本转语音和 macOS say 会选择与回复语言匹配的声音。更多本地模型在首次需要时下载，声音选择器列出所有已安装模型的声音。
- 官方 1.22.0 / 设置：每个 OpenChamber 实例单独记住主题，连接不同实例的窗口保持各自设置的外观。感谢 @kydorn。
- 官方 1.22.0 / 设置：GitHub 账户移至“设置 → 集成”。拉取请求面板提供账户控件，连接账户后才显示侧栏图标。
- 官方 1.22.0 / 文件：即使 Markdown 预览没有焦点，Ctrl/Cmd+F 也能打开预览内搜索。
- 官方 1.22.1 / OpenCode Go：OpenChamber 自行发起的请求，包括提交说明、拉取请求正文、回顾与后续建议、变更导览、目标模式检查、笔记和用量请求，均携带 OpenCode Go 自 9 月 6 日起要求的 `x-opencode-session` 请求头。聊天请求此前已有此请求头。该版本发布时建议 OpenCode Go 用户在该日期前升级。
- 官方 1.22.1 / 聊天：排队消息会保留附加上下文、文件提及和技能，编辑消息时会将它们恢复到输入框。
- 官方 1.22.1 / 工作树：归档一个工作树中的 121 个会话约需一秒；侧栏批量归档也得到相同优化。感谢 @yulia-ivashko。

- 官方 1.22.1 / Git：草稿所在目录有未提交改动时，分支选择器会显示警告。感谢 @yulia-ivashko。

- 官方 1.22.1 / 聊天：新会话会打开上次使用的聊天区或项目区。感谢 @yulia-ivashko。
